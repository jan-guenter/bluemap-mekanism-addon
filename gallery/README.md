# Disposable Mekanism gallery

Install the generated ZIP in the disposable staging world. The load function
builds a compact 39-machine composite sample, every transmitter ID, connection
mode silhouettes, four whole-block Covers, five energy-cube controls, formed
glass panels and a stock casing control within the reusable BlueMap mask. Run
`function mekanism_gallery:verify` for a quick presence check.
