# Notices

This independently authored MIT add-on interprets operator-installed resource
files from Mekanism, Mekanism Generators, Mekanism Covers, and Mekanism:
MoreMachine. No third-party model, texture, source or binary is distributed in
the add-on JAR.

The BlueMap integration uses the MIT BlueMap 5.23 feature-backport interfaces.
The four MIT Adapter API bootstrap sources are compiled into this add-on from
the exact pinned public source tree. No Adapter API JAR is bundled or nested.
